Release 2.17.1

This is a security release.

JRE Update

The JRE included with the macOS releases has been updated to 17.0.21.1+2 to fix CVE-2026-114938, aka Java2Shell / Java4Shell.

Software Signing

The Windows and macOS releases are now signed.
